# Архитектура BookFlow
Мультитенантный API: TenantId присутствует во всех бизнес-сущностях, запросы отфильтрованы по JWT tenant claim. PostgreSQL сериализует конкурентные операции записи. BackgroundService отмечает отправленные напоминания. Next.js проксирует API на внутренний контейнер. Время хранится в UTC.
